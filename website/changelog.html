Changelog

What changed

Notable changes to Aerix Launcher. The full history lives in CHANGELOG.md.

1.6 ARM32 runtime & renderer compatibility 2026-10-08

Changed

  • Updated the bundled ARM32 Java 21 runtime. The rebuilt runtime disables InlineIntrinsics to avoid a known ARM32 java.lang.Math regression, and its marker identifies the patched bundle. It passed source and ELF architecture checks, but was not tested on a physical device; Minecraft 1.20.5+ on 32-bit Android remains experimental and unverified.
  • LTW renderer selection now considers GLES support and library availability. When GLES is detected, LTW is not selected below GLES 3; its ABI-specific native library must also be present. Incompatible selections fall back where a compatible renderer is available.
  • LTW shader optimization preserves linked shader-stage inputs and outputs through post-link optimization. This source-level compatibility change does not claim to fix every device-specific rendering issue.
  • LTW's GLES/GLSL compatibility environment now includes the renderer's required GLES and extension flags.

Added

  • An automated ARM32 Java 21 build, repack and verification workflow, including runtime metadata, ARM32 ELF and Math-workaround checks.
  • Regression tests for LTW environment settings, GLES-aware renderer selection and fallback behavior.
1.5 32-bit diagnostics & mobile tuning 2026-10-08

Changed

  • Low-heap JVM auto-tuning selects SerialGC and a 48 MiB code cache for allocations up to 1280 MiB, while preserving explicit GC and code-cache choices.
  • Mobile graphics presets use shorter render distances and reduced render scales. No FPS or temperature gains are promised without device-specific testing.

Fixed

  • Memory sizing follows the launcher process ABI. On 32-bit, heap allocation accounts for the largest free virtual-address range and reserves space for JVM non-heap memory; old oversized saved values are capped.
  • Minecraft 1.20.5+ is no longer blocked solely because Android or the launcher process is 32-bit. The launcher makes a best-effort attempt when a compatible Java 21+ runtime is available. Mojang's 64-bit OS requirement remains, so this configuration is unsupported and not confirmed on real devices.
  • Surface startup diagnostics ignore zero-sized initial measurements and log requested and native buffer sizes plus buffer-geometry errors. This improves diagnosis; it does not claim to fix device-specific renderer failures.

Added

  • Regression tests for runtime selection by Java minimum and Android process ABI, included in build CI.
1.4 Microsoft login & Java compatibility 2026-10-08

Fixed

  • Microsoft device-code sign-in now selects the OAuth endpoints for the configured client: the built-in Minecraft Java client uses Live endpoints, while custom client IDs continue to use Entra consumers v2. Refreshes stay on the matching flow, Xbox RPS tickets use its matching prefix, and both verification URL field names are accepted.
  • Authentication errors retain their details. HTTP status and OAuth error information are surfaced, and blank CI client-ID values fall back to the configured default rather than producing an empty client ID.
  • Java runtime and native selection now follows the app process ABI, including 32-bit APKs on 64-bit phones. Incompatible runtimes are filtered, and Java 21–25 GC flags avoid unsupported ZGC options with a G1GC fallback where needed.

Added

  • Regression tests for OAuth client routing and response fields, Android process architecture, and GC compatibility; OAuth configuration tests now run in CI.
  • Updated repository links and GitHub Pages deployment workflow after the repository rename, plus a CNAME and canonical/social metadata prepared for aerix-launcher.gt.tc.
1.3 Instance & theme fixes 2026-10-07

Fixed

  • Landscape instance management now keeps the instance summary and Play action in a compact left sidebar with a two-column section grid, while the selected manager opens in the right pane.
  • Theme accents are consistent across the launcher. Navigation selection, primary actions, enabled switches, selected tabs and highlighted controls follow the selected launcher or wallpaper theme.
  • Reset Icon stays horizontal. Overview actions now wrap as complete controls and keep their labels on one line on narrow screens.
1.2 Interface release 2026-10-07

Changed

  • No more global top bar. The shell header — logo, page title, search, Tasks, Files and account — is gone from every screen. Pages start at the top of the display and use the full height. A slim back button appears on the left only when there is a page to go back to, and a small badge only shows in the top-right while a download runs.
  • Instance page rebuilt for short screens. On a landscape phone the sidebar is a one-line instance summary, a full-width Play button and a 2×4 grid holding every section entry, so all eight tabs stay visible. The Mods tab gets a single-row toolbar and denser rows — about four mods on screen where one and a half were readable before.
  • Create New Instance gives the Minecraft version list the whole left column, so several versions are readable at once. The selected version shows an accent outline with a check mark, and the modloader tiles match.
  • Accounts centres the + Microsoft / + Offline / + Auth Server buttons, caps the account list so it cannot push content away, and adds a skin library — search field plus a scrollable three-column skin grid with a preview dialog and an Install button that applies the skin to the current account.
  • Wallpapers grow from 20 to 25 built-in HD Minecraft wallpapers, each with its own accent theme, including a full crimson red Nether forest, amethyst geode, bamboo sunrise, badlands canyon and Deep Dark sculk presets.
  • Version name no longer carries a -debug suffix; the About page shows a clean version number.
  • The second name is gone from the app, the README and this site. entitybrian is the sole owner and maintainer.

Removed

  • The Multiplayer page and its navigation entry.
  • The standalone MC Skin screen, replaced by the skin library on the Accounts page.
1.0.0 First public release 2026-10-04

Added

  • LTW Legacy renderer (libltwlegacy.so) — a wrapper covering Minecraft 1.8 – 1.16.5, built from a vendored, pinned snapshot of GL4ES (1.1.7) for every ABI.
  • MobileGlues renderer (libmobileglues.so) — a modern OpenGL-on-GLES wrapper covering Minecraft 1.17 – 26.3, with a tuned config.json written at startup.
  • VGPU renderers (libvgpu.so, libvgpu_1368.so) — two options for Minecraft 1.16.5 and older, with Sodium and shader support.
  • 1-Tap FPS Booster — one tap applies the full mobile FPS preset, and the choice persists across restarts.
  • JRE & GC auto-tuner — tunes the Java runtime and garbage collector for the device, and remembers what it chose.
  • Smart Crash Doctor — reads a crash log and suggests the fix.
  • Mod dependency & conflict resolver — resolves missing dependencies and conflicts automatically.
  • Interface overhaul — redesigned screens with dedicated landscape layouts, a home dashboard with quick-action pills, a streamlined navigation rail, and a theme that follows the wallpaper.
  • 20 HD Minecraft wallpapers built in, with dim control, a Solid Dark mode and custom imports.
  • Rebuilt download pages — hero card, screenshots rail, and auto-detection that reads a file's Minecraft versions and loaders.
  • Full Minecraft version catalog in Discover — 69 modding-relevant releases from 26.3 back to 1.4.7, newest first, replacing a 14-item cap.
  • Minimizable modpack install dialog — shrink it to a floating button and keep using the launcher.
  • In-game Aerix Pill HUD with world and screenshot quick actions.
  • Interactive 3D paper doll — drag to spin 360°, tap to open account management.

Changed

  • The legacy GL path is now built from source. The LTW Legacy wrapper is compiled from vendored sources instead of shipping another prebuilt blob.
  • Automatic wrapper selection is wired into the launch path. Previously an instance with no renderer configured fell back to the first loaded renderer for every version.
  • The picker no longer hardcodes identifiers or version boundaries. It reads each renderer's declared compatibility window, so a renderer cannot drift out of sync with it.
  • An unsupported override is rejected up front instead of being honoured and then failing the launcher's own support check moments later.
  • Platform search falls back sequentially across sources — 15s per source inside a 30s cap — instead of racing them concurrently.
  • Wallpaper blur is a pre-rendered static image on all Android versions, removing the per-frame cost that janked tab switches and dialogs.
  • Settings and wallpaper backgrounds decode off the UI thread and share a process-wide cached bitmap.

Fixed

  • Discover search failed with "This job has not completed yet" on Modrinth and CurseForge — concurrent requests through a shared HTTP client; the sequential fallback above fixes it.
  • CurseForge outages no longer kill search — requests fall back to a mirror backup source.
  • Sodium, Embedium and Rubidium crashed instantly after joining a world on every renderer except one. The launcher now applies a crash-free chunk-backend patch to all three mods' configs on every renderer, covering both existing configs and first-run defaults.
  • Version comparison could not run in a plain JVM unit test — a missing resource stream now degrades to an empty list instead of throwing, which is what made the renderer picker testable in CI.
  • Visual lag when opening any tab, fixed by the pre-rendered blur and cached background decoding.
  • Startup and animation jank from the screen transition and software bitmap path.

Verified in CI

  • The APK verifier now checks both libltw.so and libltwlegacy.so for every requested ABI, and runs in the release workflow as well as the normal build.
  • The renderer test set now includes the LTW Legacy and renderer picker tests — the latter had never been executed by CI before.

Not yet claimed

Deliberately not claimed in this release, because they need a physical Android device running the game and have not been measured:

  • Performance (FPS, 1% lows, memory, startup time, chunk load speed) relative to any other renderer.
  • Mod, resource pack and shader pack compatibility matrices.
  • Whether the newer upstream GL4ES revision behaves identically to the build it supersedes on legacy versions.

Notes

  • LTW Legacy is derived from GL4ES, which is MIT licensed; upstream licence and copyright notices are preserved.
  • MobileGlues is LGPL-2.1 licensed by MobileGL-Dev; only its prebuilt native libraries are bundled, unmodified.
  • Released as 1.0.0, version code 200043 — kept monotonic with pre-release builds so existing installs see the update.
